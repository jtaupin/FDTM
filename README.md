This repository contains the source code used for generating the figures of the article.

`main.py` contains the main code for computing the FDTM.

`run_estimators.py` provides a function to run the FDTM estimation on several datasets.

`datasets.py` provides the dataset-generating functions used in the various examples.

`circle_utilities.py` provides some useful functions used in the circle examples.

The jupyter notebooks compute the figures. The figures are included in `figures`.
